# SchoolPiBoard Web — клиент

React + TypeScript + Vite. Клиент доски `board.school-pi.online`.

## Запуск

```bash
cd webapp
npm install
cp .env.example .env
npm run dev            # http://localhost:5173
```

В `.env` укажите адрес запущенной службы. В бою там стоит просто `/api`:
nginx проксирует API на том же домене, поэтому запросы для браузера свои
и CORS не нужен вовсе — меньше настроек и нечему ломаться.

```bash
npm run build          # проверка типов + сборка в dist/
npm run typecheck
```

`npm run build` включает `tsc --noEmit`: типы должны сходиться.

## Страницы

| Путь | Что там |
|---|---|
| `/` | главная: «ВОЙТИ» и «ЗАРЕГИСТРИРОВАТЬСЯ», описание, правовые ссылки |
| `/register` | регистрация преподавателя: имя, почта, пароль дважды |
| `/login` | вход; отсюда же высылается письмо подтверждения заново |
| `/confirm?token=` | страница из письма: подтверждает почту и сразу впускает |
| `/forgot-password` | запрос ссылки на смену пароля |
| `/reset-password?token=` | страница из письма: новый пароль |
| `/boards` | список досок — заглушка до этапа 11b |
| `/legal/terms`, `/legal/privacy`, `/legal/offer` | правовые тексты |

Страницы из писем открыты и без входа: по такой ссылке человек приходит
ещё не войдя.

## Решения

**Токен входа лежит в `localStorage`.** Он изолирован по origin, поэтому
учётные записи доски не пересекаются с учётными записями основного сайта
даже на соседних поддоменах.

**Токен из хранилища проверяется у сервера, а не принимается на слово:**
он мог протухнуть или быть выпущен прежним ключом подписи.

**Права проверяет сервер.** Клиент прячет то, что роли не положено, но это
удобство, а не защита: скрытая кнопка ничего не запрещает.

**Капчи нет.** Задание её не требует ни в одном разделе, поэтому она и не
добавлена. Вопрос стоит решить до того, как регистрация станет публичной.

## Оформление

Палитра взята с основного сайта `school-pi.online`, чтобы продукты читались
как родственные. Все цвета — переменные в начале `src/index.css`.

Фон главной (`components/BookshelfBackground.tsx`) — книжные полки, пока
статичные. Место для анимации подготовлено внутри компонента и в стилях
`.shelf` / `.book`, разметку страниц она не затронет. Подключён только
к главной: на рабочих страницах фон мешал бы.
